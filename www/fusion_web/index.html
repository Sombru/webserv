Server readiness checklist

Toggle a category to reveal questions you can use to verify your implementation.

Routing checklist:
  • Does /old redirect back to the homepage with the correct status?
  • Are default index files served for directories missing explicit filenames?
  • Can you toggle autoindex for /images without impacting siblings?
CGI checklist:
  • Are environment variables such as REQUEST_METHOD and QUERY_STRING populated?
  • Does your server stream script output while preserving headers?
  • Can scripts without extensions, like test_noext, run successfully?
Upload checklist:
  • Do multipart requests save to /images/uploaded_images?
  • Is raw POST data captured correctly by the textarea form?
  • Can you delete files and observe the response code your server returns?
Error checklist:
  • Is the custom template at /error.html displayed for missing routes?
  • Do you return 405 when hitting routes with disallowed methods?
  • Are timeouts and body size limits honored with descriptive messages?
