Manage uploaded images.

This directory serves GET requests and accepts POST uploads and DELETE removals. Use the quick actions below or hit it directly with curl, Postman, or your own client.

Upload or remove files

Choose a file to POST directly to this directory, or issue manual requests to test method handling.

Allowed: GET Allowed: POST Allowed: DELETE
Example commands 
curl -F 'file=@cat.png' http://127.0.0.3:8080/images/

				
curl -X POST --data-binary @notes.txt -H 'Content-Disposition: attachment; filename=notes.txt' http://127.0.0.3:8080/images/

				
curl -X DELETE http://127.0.0.3:8080/images/uploaded_images/notes.txt
Hint: the Upload Lab page can create files from raw POST bodies as well. Try both flows to validate your handlers.
