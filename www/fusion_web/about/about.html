Fusion Web Playground

Fusion Web is a curated playground built to validate servers that power CGI driven applications. Each page is designed to stretch routing, HTTP, and dynamic response features while keeping things fun to explore.

What this project exercises

6 HTTP methods in action

We cover GET, POST, DELETE, and custom scenarios to make sure your server handles the common verbs with ease.

3 CGI runtimes

Python, Bash, and executable binaries all live under /cgi-bin/ and echo back headers, bodies, and env vars.

40+ Edge cases covered

From redirects to uploads and directory listings, every route gives your implementation another chance to shine.

Pick a focus

Select a tab to discover more about how Fusion Web helps you validate specific pieces of the puzzle.

Runtime checks: Inspect how your server forwards headers, handles payload sizes, and streams output from Python and Bash scripts. Try editing the request body in the CGI demo to validate chunked transfers or encoding decisions.
Routing tests: Navigate from / to /old and back, ensuring redirects and default indexes are being respected. Toggle autoindex on /images to verify directory listings and file manipulation.
Toolbox: Use the upload form, 3D animations, and error templates to validate MIME detection, caching headers, and graceful error recovery. These scenarios mimic a production-ready pipeline.
